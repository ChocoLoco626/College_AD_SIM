# College AD Simulator V14

Run with `streamlit run app.py`.

V14 adds:
- 0-100 program prestige progression that rises/falls meaningfully with sustained success, postseason results, facilities and NIL.
- Current-season W/L records reset every July 31 while career/all-time records remain.
- Coach program-fit system, coach satisfaction tied to fit, and salary renegotiation.
- Persistent booster personalities, confidence and dynamic funding for NIL/facilities.
- Wider school budget differentiation.
- Year-over-year financial history with line and bar charts.
- Existing career/job market, postseason, schedules, conference standings, rankings and history systems retained.

This is a simulation and uses the included school dataset rather than claiming an exact official membership count.

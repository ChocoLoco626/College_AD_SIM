# College AD Simulator V6

A Streamlit college athletic director career simulator.

## V6 systems

- Career mode with persistent saves
- Generated persistent ADs, presidents, and coaches
- Head-coach management:
  - fire coaches
  - view buyouts
  - hire coaches from the wider coaching market
  - coach ratings, recruiting, development, personality and contract length
- NIL allocation by sport
- Booster-funded facilities and targeted department investments
- Persistent regular-season results
- Postseason engine:
  - 2026-27 College Football Playoff
  - CFP first round, quarterfinals, semifinals and national championship
  - non-CFP bowl games
  - 2027 NCAA men's basketball tournament (76-team format)
  - 2027 NCAA women's basketball tournament (76-team format)
  - postseason game scores and round-by-round results
  - school postseason history
  - national championship history
- Postseason results affect the AD résumé and board evaluation
- 2026-27 calendar
- Job market and career mobility

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit deployment

Set the Streamlit entry point to:

`app.py`

Make sure the repository contains:

```text
app.py
simulation.py
postseason.py
management.py
game_state.py
world.py
career.py
database.py
names.py
calendar_data.py
requirements.txt
data/schools.json
```

## Notes

The current school file is the project's 343-school seed dataset inherited from V5. It is not yet a verified complete NCAA 361-school master list.

The postseason model is a simulation system rather than a live NCAA bracket feed. It uses the 2026-27 CFP dates and the 2027 NCAA 76-team basketball format as the structural calendar, while game participants and outcomes are generated by the saved simulation world.
